# EventShock Lab Limitations

## 结论边界

EventShock Lab 输出是条件化的模型情景结果，不是价格预测、估值、投资建议、交易信号或因果估计。结果只在当前 Event Pack、Agent、市场机制、参数、模型、提示词、缓存和随机种子范围内成立。

## 数据限制

- SpaceX Demo 不包含可再分发的真实逐笔、订单簿、价差、深度、成交量、NDX 或 QQQ 序列。
- 发行价 135 美元只是仿真参考，不是 7 月 7 日市场价格。
- IPO 售出股数不是自由流通股或立即可交易供给。
- Nasdaq 跟踪产品管理资产不是对 SPCX 的购买流量。
- Reuters/JPMorgan 被动流估计晚于观察截止时间，且缺少完整方法和区间，因此不进入仿真。
- 日期型来源经过明确的 UTC 日末归一化，不能被解释为秒级发布时间。
- 外部链接可能失效或内容变化；仓库没有保存完整受版权保护快照。

## 市场模型限制

- 单资产、单订单簿和单进程实现省略了多场所路由、隐藏订单、开收盘竞价、复杂订单、交易费用、税、结算失败和多数市场制度。
- 合成做市商深度、风险规避流、被动流和恢复路径没有根据 SPCX 真实订单簿校准。
- 价格由模型内部订单形成，不能映射为真实资产未来价格。
- Agent 人群是合成原型，不是实际持有人、机构或投资组合。
- FTSE Russell 纳入和 250 亿美元高级票据事件造成明显历史混杂，模型没有识别 Nasdaq 纳入的独立现实因果效应。

## 统计限制

- 默认 10 个 matched seeds 对尾部和不稳定机制的估计较粗。
- 经验 95% 区间不是参数化总体置信区间。
- 多个指标同时展示会增加事后选择和故事化风险。
- 代表性 trace 只是解释路径，不是概率最大路径。
- 仓库已有模型内部 Study 预注册契约，但没有事前独立时间戳的真实历史研究预注册、holdout 历史结果或外部复算证据。
- 当前没有对 calibration profile 做真实历史外样本检验。

## LLM 限制

- 严格结构化输出不能消除幻觉、遗漏、注入、偏差或过度自信。
- 供应商可能在模型 ID 不变时改变行为。
- 实时 GLM 模型的质量、延迟、成本、拒答率和中英文等价性没有形成仓库证据。
- Code grader 只能检查已编码规则，不能全面判断事实真实性与金融误导。
- 规则回退安全但可能降低模拟行为多样性。
- 不可变缓存改善重放，但缓存本身会固化当时模型错误。

## 安全限制

- 匿名 Session ID 不是账号认证或强授权机制。
- 普通用户 BYOK Key 位于进程内存；部署指定管理员的一份可选持久凭据使用应用层 Fernet 静态加密。两者都不是硬件或专用 Secret Vault；主机 root、Docker 管理员、运行中应用、调试器和恶意依赖仍可能取得明文。
- 管理员凭据主密钥丢失会使现有密文不可恢复；主密钥与 SQLite/备份同时泄露会失去静态加密保护。当前没有完成主密钥轮换、恢复和泄漏处置的人工作业演练。
- 当前未完成主机、日志、Crash Dump、TLS、备份、恢复和容器供应链的独立安全审查。
- 当前没有对所有红队用例形成实际执行 artifact。
- SQLite 适合低流量控制面，不适合高并发多租户写负载。
- Event Pack 抽取前的确定性扫描可阻断已登记的 prompt injection、活动代码、凭据和高风险 PII，并要求中低风险内容确认/脱敏；它不是附件反病毒沙箱、完整 DLP 或隐私合规证明。
- 单个已完成实验可以保留底层证据并标记为 `INVALIDATED`，此后结果、子资源与导出会阻断有效研究使用。
- 批量将受影响实验标为 `INVALIDATED` 的能力尚未实现，是明确的 incident response 缺口。

## 隐私限制

- 系统只有已登记类别的确定性 PII/Secret 初筛，没有完整 PII 检测、删除请求和数据主体工作流。
- 用户不应上传真实个人交易记录、受监管个人数据或不允许发送给第三方模型的材料。
- 社交网络是合成的；若未来接入真实社交数据，需要重新完成许可、隐私和伦理审查。

## 公平与代表性限制

- 规则与 Persona 参数可能无意中强化“散户不理性”等刻板印象。
- 主要事实来源为英文和美国机构，不能代表其他司法辖区的信息生态。
- 当前没有真实用户证明中英文界面传达相同限制。
- 系统不应用于对真实个人或群体做能力、理性或可信度判断。

## 运营限制

- 服务器为单实例、低内存自托管方案，没有高可用集群。
- 进程重启会把活跃 Experiment 标记为 `FAILED_RETRYABLE` 并清除普通用户内存 BYOK；重新启动时只能复用哈希匹配的完整 matched-pair checkpoint 与已冻结认知 tape，半完成配对不恢复。若中断前没有可用认知 checkpoint，普通用户混合模式可能需要重新填写 Key；只有部署指定管理员明确启用且密文与主密钥均有效时，持久凭据才能在重启后继续使用。
- 实时模型依赖外部网络、账户余额、配额和供应商可用性。
- Incident response、备份恢复、回滚和网络降级尚未完成具名人工演练。
- 低内存限制下需要限制并发实验、LLM 节点和上传大小。

## 人类证据状态

以下项目全部为 `PENDING_HUMAN_EVIDENCE`：

- 目标用户可用性和理解研究。
- 独立领域专家批准。
- 模型风险验证。
- 部署安全审查。
- 第三方许可与数据治理审查。
- Incident rehearsal。
- 双语等价性评估。

在这些证据完成前，系统只能称为课程演示和受控研究原型。
