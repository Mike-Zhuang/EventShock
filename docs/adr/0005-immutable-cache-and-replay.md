# ADR 0005：LLM 响应采用不可变缓存并优先重放

- 状态：当前 MVP 已接受
- 日期：2026-07-15
- 负责人：EventShock Lab 工程团队

## 背景

外部模型可能升级、限流、收费或返回不同内容。若每次重放都重新调用模型，同一个实验无法保证认知信号一致，成本和隐私暴露也会增加。

## 决策

缓存键必须包含提供方、模型、提示词哈希、Schema 版本、智能体配置哈希、观察哈希和采样配置。已存在键只能返回原响应；同键写入不同有效载荷必须报冲突，不允许静默覆盖。重放优先读取缓存，只有明确允许且具备有效 BYOK 凭据时才发起外部调用。导出包记录相关版本与哈希，但不包含密钥。

## 被否决的方案

- 仅按用户文本缓存：不同提示词、模型或 Schema 会错误共享响应。
- 后写覆盖：会使历史实验的含义随时间改变。
- 每次实时调用：不可复现，也增加外部依赖与成本耗尽风险。

## 后果

同一认知输入可以审计和重放，并能在模型不可用时继续演示已有案例。代价是缓存需要生命周期和空间管理；模型或提示词任何实质变化都会生成新键，不能沿用旧验证结论。

## 验证与复审

自动化测试应验证键的组成、冲突拒绝和敏感字段排除。跨版本长期重放、缓存迁移及提供方条款兼容性尚未经过独立审计，证据状态为 `PENDING_HUMAN_EVIDENCE`。
