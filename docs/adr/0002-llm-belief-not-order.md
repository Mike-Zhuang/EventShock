# ADR 0002：LLM 只形成受约束认知信号，不直接下单

- 状态：当前 MVP 已接受
- 日期：2026-07-15
- 负责人：EventShock Lab 工程团队

## 背景

项目需要展示叙事、证据和社会影响如何改变模拟参与者的信念，但不能让概率模型直接控制价格、资金或真实账户。自由文本输出也不能直接进入确定性市场内核，否则格式漂移和提示词注入会影响执行安全。

## 决策

LLM 输入只包含经过时间与来源约束的观察、智能体配置和版本化系统提示词。LLM 输出必须通过严格 JSON Schema 验证，形成有限字段的信念更新与行动偏好。确定性策略再把这些信号转换成模拟订单意图；撮合引擎独立决定订单是否成交及成交价格。LLM 没有网络浏览、文件写入、真实交易、支付或系统命令工具权限。

## 被否决的方案

- 让 LLM 直接输出并提交订单：扩大行动权限，难以证明价格和数量约束始终成立。
- 让 LLM 直接设置市场价格：破坏市场机制的可解释性和可复现性。
- 完全不用认知模型：无法研究叙事与异质信念传播，这是项目的核心研究问题之一。

## 后果

该边界把非确定性限制在可缓存、可校验的信号层，并允许规则智能体作为降级路径。代价是模拟不能表示所有复杂交易策略，且输出质量仍依赖模型、提示词和输入证据。任何面向真实投资决策的用途都超出本系统边界。

## 验证与复审

Schema、越权动作、提示词注入和输出漂移应由自动化红队用例持续验证。领域专家确认认知字段足以表示目标行为、用户能正确理解 AI 边界的证据状态均为 `PENDING_HUMAN_EVIDENCE`。
