# ADR 0003：以 `knownAt` 执行 point-in-time 信息约束

- 状态：当前 MVP 已接受
- 日期：2026-07-15
- 负责人：EventShock Lab 工程团队

## 背景

事件研究最严重的失真之一是把事后才知道的信息放进事前决策。来源发布日期、事件实际发生时间和系统摄取时间可能不同，只使用一个日期字段无法判断模拟参与者在某一时刻是否有权看到该证据。

## 决策

每条可进入认知层的证据都必须具有带时区的 `knownAt`。在模拟时刻 `t`，系统只允许读取 `knownAt <= t` 的内容。事件发生时间、来源发布时间和采集时间可以作为额外元数据保留，但不能替代 `knownAt`。缺少可审计时间的信息默认不可用于严格 point-in-time 运行。

## 被否决的方案

- 按文件顺序提供证据：顺序不代表当时可知性。
- 只按事件发生时间过滤：媒体确认和市场获知可能晚于事件本身。
- 缺失时间时自动推断为事件时间：会制造无法追溯的未来信息泄漏。

## 后果

实验可以明确回答“当时已知什么”，并对 future leakage 进行机器检查。代价是数据准备更严格，部分来源因时间不清晰而被排除；时区转换和夏令时也必须保持一致。

## 验证与复审

模型验证和测试应拒绝无时区时间，并验证边界时刻的可见性。所有 SpaceX 证据时间仍需人工逐条核对原始页面，当前证据状态为 `PENDING_HUMAN_EVIDENCE`。
