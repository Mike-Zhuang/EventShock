# ADR 0008：SpaceX 案例严格区分真实事实层与合成市场层

- 状态：当前 MVP 已接受
- 日期：2026-07-15
- 负责人：EventShock Lab 工程团队

## 背景

SpaceX 相关事件具有教学吸引力，但 SpaceX 并非公开上市公司，无法把其私人证券事件伪装成可直接回测的公开股票订单簿。案例同时包含公开来源事实、分析者假设和为模拟构造的市场变量，若混在一起会误导用户。

## 决策

Event Pack 将内容分为三类：带 URL、来源层级和 `knownAt` 的公开事实；明确标注为假设的反事实干预；明确标注为 synthetic 的市场、参与者、流动性和价格输入。默认演示研究 SpaceX 事件对合成风险资产或相关市场机制的传播，不声称预测 SpaceX 股价、上市日期或真实投资回报。UI、导出和验证报告都必须保留这些标签。

## 被否决的方案

- 为 SpaceX 伪造历史股票价格：会把合成数据冒充真实观测。
- 只展示新闻摘要：无法运行机制实验，也不能回答反事实问题。
- 把第三方估计提升为官方事实：破坏来源层级和证据可追溯性。

## 后果

演示既能使用真实事件背景，又不跨越私人公司数据边界。代价是结果只能解释为模型内场景分析，不能与真实 SpaceX 股票表现对照。新增来源必须通过时间、许可和层级审查。

## 验证与复审

机器验证应检查来源字段、synthetic 标签和干预声明。所有来源内容、许可、层级与叙述准确性需要人工核验，当前状态为 `PENDING_HUMAN_EVIDENCE`。
