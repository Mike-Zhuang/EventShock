# ADR 0004：基线与干预实验使用 matched seeds

- 状态：当前 MVP 已接受
- 日期：2026-07-15
- 负责人：EventShock Lab 工程团队

## 背景

本项目比较只改变一个干预变量时结果如何变化。如果基线与干预使用不同随机种子，观察到的差异会混入不同随机路径造成的噪声，降低统计效率，也使机制追踪困难。

## 决策

每个基线运行都必须与一个使用相同 seed 的干预运行配对。比较统计量以同 seed 的 `intervention - baseline` 差值为基础，输入数量或 seed 集合不一致时直接拒绝计算。报告中的区间为配对差值样本的经验分位区间，不把它描述为经理论覆盖率证明的总体置信区间。

## 被否决的方案

- 两组独立随机种子：需要更多运行才能分离干预效应与路径噪声。
- 只运行一条路径：无法展示随机性与敏感性。
- 运行后按相近结果配对：引入选择偏差，且无法忠实重放实验设计。

## 后果

比较更稳定，单条差异也能追溯到同一随机路径。代价是两组实验必须严格同步随机数消费；如果代码分支改变随机调用顺序，匹配只保证 seed 相同，不保证每一步随机冲击完全对应。

## 验证与复审

自动化测试应覆盖数量不等、seed 不等和差值方向。运行次数、区间解释和统计口径是否适合课堂与目标用户的证据状态为 `PENDING_HUMAN_EVIDENCE`。
