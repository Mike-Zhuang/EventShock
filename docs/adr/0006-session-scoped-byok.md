# ADR 0006：BYOK 密钥仅保存在会话级内存中

- 状态：部分被 ADR 0012 取代；普通用户和管理员未主动启用持久保存时仍适用
- 日期：2026-07-15
- 负责人：EventShock Lab 工程团队

> 2026-08-03 状态说明：本 ADR 的会话内存方案继续作为所有普通用户的唯一模式和部署指定管理员的默认模式。只有部署指定管理员明确选择持久保存时，才适用 [ADR 0012](0012-admin-persistent-provider-credential.md) 的受限例外。

## 背景

用户需要在前端填写自己的智谱 API 密钥进行可选的 LLM 运行。把密钥写入 SQLite、日志、导出包、浏览器持久存储或仓库会扩大泄漏面，而当前 MVP 没有成熟的密钥管理服务和用户身份系统。

## 决策

服务端按匿名会话保存密钥，只驻留进程内存并设置 TTL；对外只返回掩码状态。密钥字段禁止进入日志、异常正文、数据库、缓存键、实验快照和导出文件。进程重启、会话到期或主动删除后密钥不可恢复。生产 HTTPS 由反向代理终止，HTTP 请求重定向到 HTTPS。

## 被否决的方案

- 明文保存在 SQLite：磁盘备份和数据库读取都会暴露密钥。
- 保存在浏览器长期存储：页面脚本或共享设备风险更高。
- 由项目提供统一平台密钥：无法隔离成本和配额，并增加运营责任。

## 后果

静态数据泄漏面较小，用户明确承担自己的模型调用费用。代价是进程重启会丢失密钥，多进程部署无法自然共享会话，匿名会话标识也不是强认证。该方案只是 MVP 风险降低措施，不是通用秘密保险库。

## 验证与复审

自动化测试应检查掩码、TTL、删除和序列化边界；日志与导出中的秘密披露需要人工安全审查。渗透测试和独立安全批准状态为 `PENDING_HUMAN_EVIDENCE`。
